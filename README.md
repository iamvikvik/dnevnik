# Дневник

Заметки и личный дневник в одном приложении. Свайп влево-вправо переключает разделы.

Как поставить:
1. Создай на GitHub новый репозиторий (например, diary).
2. Загрузи в корень все файлы из этой папки: index.html, sw.js, manifest.webmanifest, icon-192.png, icon-512.png, apple-touch-icon.png.
3. Settings → Pages → Branch: main / root.
4. Открой ссылку в Safari на iPhone → «Поделиться» → «На экран Домой».

Данные хранятся только на телефоне. Делай резервную копию: Настройки (шестерёнка) → «Сделать резервную копию» → сохрани в «Файлы».
